The accent — six explorations

The stem is settled: it varies with the space available, single inside the word and a barcode inside the mark, because the beam is what joins them. So the accent is the one shape that has to work everywhere, and it is the only variable on this sheet. Each row shows the same accent in all four places it lives. The glyph is now built in em units from the measured font and anchored to the text baseline, which round one did not do.
